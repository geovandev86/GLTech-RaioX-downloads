# GL Tech Raio-X · downloads

Diagnóstico de PC e de **servidor de loja/farmácia** da GL Tech: banco de dados (SQL Server), backup, certificado digital,
hora, SEFAZ, energia e rede, com nota de saúde e relatório no Telegram quando o servidor liga.

## ⬇️ Baixar a versão mais nova

**https://github.com/geovandev86/GLTech-RaioX-downloads/releases/latest**

Na página, em *Assets*, clique em `GLTech-RaioX-vX.Y.exe`. Não precisa instalar nada nem entrar no GitHub.

## Como usar
- Abra o `GLTech-RaioX-vX.Y.exe` (pede permissão de administrador). Na primeira vez demora alguns segundos para abrir.
- Se aparecer "O Windows protegeu o computador", clique em **Mais informações** › **Executar assim mesmo**.
- No servidor da loja: **LOJA › Servidor da loja › VERIFICAR**.
- Relatório no Telegram sempre que o servidor ligar: no quadro **Relatório ao ligar**, cole o token do bot
  (@BotFather › /newbot), mande um "oi" para o bot, clique **DESCOBRIR**, ligue a opção e clique **SALVAR**.

Este repositório tem só os arquivos prontos de cada versão; as versões anteriores continuam na aba *Releases*.
